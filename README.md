
# Distributed Communication Network Model

## Objective
To simulate distributed communication primitives and message-passing scenarios.

## Technologies
- Python 3
- Git
- Visual Studio Code

## Features
- Unicast communication
- Broadcast communication
- Multicast communication
- Request-reply communication
- Message inbox management

## How to Run

```bash
python distributed_network.py
```

## Project Type
Educational simulation of distributed computing communication.
